The Midnight Vault — a top-down heist game: sneak past guards and cameras, crack the vault, steal every piece of loot, and slip out the getaway door. Three jobs (museum, bank, penthouse), vision cones you have to read before you move, coins to throw as distractions, and an alarm meter that decides whether the night ends in a getaway or a pair of handcuffs. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
